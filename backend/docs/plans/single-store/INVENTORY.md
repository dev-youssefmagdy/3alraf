# Single-store conversion — Phase 1 inventory (BA)

Source of truth for Phases 2–10. Read together with `/var/www/3alraf/REMOVE_MULTI_TENANCY_PLAN.md` (§1 decisions).
Survey date 2026-11-06, branch `single-store`, DB `3alraf` (local). Raw numbers: 943 routes (507 `tenant.*`, 157 `central.*`, 161 `api.*` = 2× mobile API, 77 `storefront.*`, 35 `integration.*`), 111 tables with `tenant_id`, 216 permissions (59 `central` + 157 `tenant`), 1121 backend files matching `tenant|central`.

Legend: **ADD** = page exists only in central → add it to the panel. **MERGE** = same page exists in the tenant panel → keep the tenant one (rename to `admin.*`), drop the central copy, fold any extra behaviour in. **DROP** = only meaningful with several tenants (say where useful bits go).
Route-name rule: `tenant.X` → `admin.X`; `central.X` → `admin.X` unless stated otherwise.

## E. Behavioural risks (with code locations)

1. **Old subdomain URLs live outside the DB** — printed QR codes (1192 `qr_codes.url` = `http://egy.3alraf.loc/ar/product/...`, `QrCodeManager::url()` L352/L386), affiliate links shared by affiliates (`AffiliateTracker` L61, `Api/V1/AmbassadorController` L55), e-mails already sent (`OrderNotification` L57, `CustomerOrderNotification` L51), sitemap submitted to search engines, payment gateway callback/webhook URLs (E.3), app builds hitting `egy.domain/api/v1`. → Keep a permanent nginx/Laravel **301 from `{slug}.domain` (and `www`) to `APP_URL` same path** and run `qr:rebuild` after conversion. This conflicts with §1.1 "no subdomains" literally — lead's call (recommend: redirect only).
2. **Cross-tenant aggregation**: `ReportRepository::rate()` (`t.currency_rate` when `$f->central`), `ReportRepository::tenantBreakdown()` + L273 groupBy `t.currency_rate`, `ReportService` L39/L51/L87-90 (tenant column, base currency `config('tenancy.base_currency')`), `ReportFilter::fromRequest($r, $central)` (`selected_tenant_id()`), `CentralErpService::overview/groups/inventory/parties/periods/statements`, `ExchangeRates::find(…, $tenantId)`, `AnomalyService::detect(?array $tenantIds)`/`countsByTenant`, `HandlesReports::export` filename `current_tenant()->slug`. With one store rate=1 → remove the branches; update `docs/CALCULATIONS.md` §Reports.
3. **Payment webhook / return URLs are per-tenant host**: `OrderPaymentService` L151-152 (`tenant_url(current_tenant(), '/{locale}/payments/return/{token}')`, `'/webhooks/payments/{method}'`), hint in `views/tenant/payment-methods/form.blade.php` L46, route `webhooks.payments` in `routes/storefront.php` (tenant domain). Gateways configured with `https://egy.domain/webhooks/payments/{id}` must be re-registered (or covered by the E.1 redirect — **POST webhooks do not follow 301**, so the old host must proxy/serve them, not redirect; nginx `return 307` or serve the app on the old host too).
4. **Google OAuth**: `GoogleAuthService::callbackUrl()` L32 builds `{scheme}://central_domain/auth/google/callback`; `GoogleAuthController` state/handoff carry `t`/`tid` and redirect `tenant_url($tenant, '{l}/auth/google/complete?token=…')` L71; check L82 refuses mismatched tenant. Redirect URI in Google console must equal the new `APP_URL` host + `/auth/google/callback`.
5. **Unique validation scoped by tenant** (D.8) and DB uniques (C.2) — with 1 tenant no data conflict; risk only in the nullable-tenant tables (`auth_settings`, `whatsapp_*`, `erp_exchange_rates`) and the admin merge (`super_admin_slot`, phone).
6. **"All tenants" loops** in commands/jobs: `ApproveAffiliateCommissions` L18 (`app()->instance('currentTenant')`), `Erp{Backfill,Depreciate,Reconcile,Verify}`, `Growth{Aggregate,Engage,Operate,Prune,ScanLowStock,EvalClassifier,ExportLabelingSample,N8nSelftest,Enable}`, `RebuildQrCodes`, `GenerateApiDocs`, `ProvisionSuperAdmin`, jobs `RunAiGenerationJob`/`RunMarketTrendsJob`/`RunGlobalMarketTrendsJob`/`SyncQrCodesJob` (`Tenant::find($this->tenantId)` → job silently no-ops if tenant missing), `ResolvesOrderAdmins` (TenantContext). Pending serialized jobs in `jobs`/`failed_jobs` carry `tenantId` → drain/flush queue before migrating.
7. **Timezone**: `config('app.timezone')='UTC'` but `ResolveTenant::activate()`, `TenantContext::run()`, `IntegrationAuth` L52-53 switch PHP default tz to `Africa/Cairo` per request. Central/console code ran in UTC. Existing timestamps are therefore mixed (tenant requests wrote Cairo wall-clock, console/central wrote UTC). Phase 3/5 must set `store()->timezone` once at boot for web, console and queue (e.g. `AppServiceProvider::boot` after DB is available) and not per request; document that historic rows are not converted.
8. **Admin login / OTP / roles**: `AdminLoginController` L83 lets a **central super admin skip OTP** (`$guard === 'central' && isSuperAdmin()`) — decide whether the merged super admin keeps that; `GuardsLogins::lockoutKey` (`central`), `AuthSettings::for(?tenantId)` (OTP length/ttl per owner), `AccessService` role prefix `t{id}:` + SYSTEM roles, `Gate::before` super-admin, `erp.access` gate `guard_name === 'tenant'` (AppServiceProvider L52) — if not changed, ERP hub/menu disappears for non-super admins after guard rename. `EnsureAccountActive` / `SessionRevoker` / `RevokesSessionsOnLockout` iterate guard names.
9. **WhatsApp ownership**: connected device = central session `session_id='central'` (Node auth dir `WA_AUTH_DIR/central`); tenant session disconnected. Choosing a new fixed id (e.g. `store`) forces a QR re-pair. Recommend fixed id = `central` (rename later only if needed) or Node maps old ids. Locations: `WhatsappSession::idFor()` L26, `WhatsappService::session()` L19-23, `ownerOf()` L130 regex, `MediaPaths` L10, `session-manager.js` L18, channels (`routes/channels.php`), `SessionUpdated::channelName`, `ResolvesChatOwner`, `ConnectionController::owner()`, OTP sender uses `AuthSettings::for($tenantId)` of the login panel (tenant admins got OTP via the tenant session which is disconnected → today tenant OTP delivery fails; after merge it will use the connected session — behaviour change, good).
10. **Sitemap / robots / SEO canonical**: `Storefront/SitemapController` (current_tenant locales), `Storefront/RobotsController` (sitemap URL), `components/layouts/storefront.blade.php` L14 canonical `url()->current()`, L55-56 hreflang `x-default` from `$tenant->default_locale`, `SeoSettingsService` (settings.seo). Canonical host changes from `egy.domain` to `APP_URL` → needs E.1 redirect for SEO equity; `central.robots` and `storefront.robots` both answer `/robots.txt` today (domain split) — merge carefully.
11. **Storage**: `PrivateFileController` L15 only serves `tenants/{current_id}/…` → must still serve legacy `tenants/1/…` (payment proofs, expenses) and the new prefix-less paths; `ImageUploadService` L30-35 picks `tenants/{id}/` vs `catalog/` by context (central uploads went to `catalog/`); `ImageOptimizer` L46 regex; `PruneOrphanMedia` roots — must keep `tenants/` in the scan or files are reported orphan/deleted.

The master switches were in central (`central.ai.tenants.edit`, `central.tenants.growth`). In the merged panel the switch pages (Store settings growth card, AI platform card) must be reachable while the feature is OFF.
13. **Rate limiting keys** (`AppServiceProvider::tenantKey()` L100-115) query `tenants` by host/X-Tenant on every request before routing — must become constant; `api.v1.h.*` twin bucket logic (`routeKey`).
14. **Mobile API compat**: old app builds call `GET {central}/api/v1/tenants` then send `X-Tenant: egy` to central host, or call `egy.domain/api/v1/...`; `ApiContext` aborts 404 `store.api.tenant_not_found` when the header slug is unknown — after the change it must ignore the header entirely (even unknown slugs). Old builds on `egy.domain` need the host to keep answering (E.1/E.3: proxy, not redirect, for POST).
15. **Session cookies**: `.env.production.example` says no SESSION_DOMAIN so each subdomain has its own cookie; moving admin + storefront to one host merges cookies: customer (`web`) and admin sessions now share one session → logging out an admin (`session()->invalidate()`) logs the customer out in the same browser; guest cart in session. Check `AdminLoginController@logout`, `LoginController@logout` invalidate behaviour.
16. **URL defaults / route params**: `URL::defaults(['tenant' => slug])` (ResolveTenant L38) + every `route('storefront.*', ['tenant' => …])` in `bootstrap/app.php` L65-81 and any call passing `'tenant' =>` (31 files contain `'tenant' =>`, also event payload keys). Remove the param or Laravel appends `?tenant=egy` query strings.
17. **Audit/activity semantics**: `ActivityDataTable` tenant filter, `Audited` stamps `tenant_id`, `ResolvesChatOwner::audit` taps `tenant_id`, `GrowthAccess` growth toggle audit swaps `currentTenant` (TenantController L73-76). Activity rows with `tenant_id NULL` (456 central) become visible to the single panel's audit page (desired).
18. **Notifications routing**: `NotificationController` L54-56 maps payload `tenant_id` → `route('central.tenants.edit')` (crash after route removal for the existing row) → delete `TenantNotification` rows in the migration.
19. **Fresh-install path**: DatabaseSeeder creates 2 tenants (`egy`, `sa`); old seed migrations run `PermissionSeeder`; migration order (C.6) — `migrate:fresh --seed` must end with exactly 1 store and the conversion must not abort on a fresh empty DB (0 rows in `tenants` → create store id 1 from config).
20. **Two `/admin` panels with the same URIs** (all MERGE rows in A.1 share URI and name suffix) — only one may be registered; route-name collisions for ADD pages: none (verified: no tenant route has the same URI/name as Languages, Products, Categories, Brands, Tags, Attributes, AI providers/models/usage, ERP anomalies).
21. **ERP central views reused**: `central/erp/_alerts.blade.php` IS included by `views/tenant/erp/hub.blade.php` L28 (+ lang `erp_central.alerts.none`) — when deleting `views/central/erp/*`, keep `_alerts`, `_money`, `anomalies` (moved), delete the rest.
22. **`erp_owners.tenant_admin_id`** links ERP owners to admin accounts (lang key `validation.attributes.tenant_admin_id`); renaming the column touches `OwnerService`, owner forms and requests.
